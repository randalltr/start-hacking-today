# Chapter 8: Next Steps

## You Are Now Dangerous

At this point, you know enough to be dangerous.

You can:

- scan a target with Nmap
- identify services
- research vulnerabilities with ExploitDB
- interact with web apps using Burp Suite
- gain access and escalate privileges

That is real hacking.

You are no longer guessing. You have a process.

Now the goal is simple.

Do it again. And again. And again.

## Hack The Box: Your Training Ground

The fastest way to improve is repetition.

Hack The Box should now become part of your routine.

Here are ten beginner-friendly machines to work through:

1. Blue
2. Knife
3. Cap
4. Netmon
5. Legacy
6. Optimum
7. Devel
8. OpenAdmin
9. Shocker
10. Arctic

Do not rush them.

For each machine:

1. Run Nmap
2. Write down every service
3. Investigate each one
4. Search ExploitDB
5. Try to gain access
6. Escalate privileges

If you get stuck, use your resources:

- YouTube (especially IppSec)
- AI tools
- Google: `htb <boxname> walkthrough`

The goal is not speed. The goal is understanding.

## Your First Certification

At some point, you may want structure and validation.

A strong first certification is:

**TCM PNPT (Practical Network Penetration Tester)**

Why this one:

- taught for beginners but guides through modern advanced attacks
- hands-on and practical
- focuses on real-world methodology
- teaches enumeration and attack paths clearly
- more approachable than OSCP

It builds a strong foundation before moving to more advanced certifications. This certification doesn't yet have the notoriety of the OSCP but it teaches the practical skills for Day 1 Penetration Testers.

## Learn to Take Notes

Your notes will become one of your most valuable assets.

Start documenting:

- Nmap results
- services and versions
- exploits you tried
- commands that worked
- mistakes you made

A simple format:

```
Port: 80
Service: HTTP
Notes: Apache default page
Next step: directory enumeration
```

Use any tool you like:

- Notion
- Obsidian
- Markdown files

The tool does not matter. Consistency does.

## Metasploit (Optional Next Step)

You intentionally avoided Metasploit in this book because it is easily detected and generally not allowed on exams like the OSCP.

That was to build real understanding first.

Now you can explore it.

Metasploit allows you to:

- quickly test known vulnerabilities
- automate exploitation
- manage sessions

Use it as a tool, not a crutch.

Always understand what the exploit is doing.
